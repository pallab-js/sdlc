# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2026-05-25
### Added
- Initial project scaffolding and folder structure.
- `Package.swift` SPM manifest with dependencies for GRDB, swift-log, and MarkdownUI.
- Database service supporting SQLite migrations 001 to 010.
- Repository layer and models for Workspaces, Projects, and Tasks.
- Shell SwiftUI navigation layout for all 10 modules.
- Unit and integration tests validating database migrations and repositories.
