# Product Roadmap — Offline SDLC Platform

## Phase 1 — MVP (v1.0)
*   **Workspace Management:** Local directories, path mapping, and SQLite-backed workspace registry.
*   **Projects & Tasks:** Full board workspace, Kanban-style views, task tracking.
*   **Requirements & Issues:** Linking SRS requirements to bugs and tasks.
*   **Local Wiki:** Offline Markdown rendering, linking.
*   **Git Integration:** Commit history, status, local diff viewer.
*   **Full-Text Search:** Query indexing with SQLite FTS5.

## Phase 2 — Extended Core (v1.5)
*   Test case creation and execution logs.
*   Requirements verification matrix.
*   Exporting reporting summaries (PDF/CSV/Markdown).
*   Visual sprint reports using Swift Charts.

## Phase 3 — Enterprise Readiness
*   Local network peer-to-peer sync (zero-trust, local Wi-Fi / LAN).
*   Encrypted local database vault with SQLCipher.
*   Local AI assistance integrating Ollama / Llama.cpp for summarizations.

## Phase 4 — Platform Expansion
*   Local plugin scripting engine.
*   Custom workflow automation hooks.
